# 35단계 검증 기록 — 복합 업무의 세부 계획 생성

## 원본과 작업 경계

- 이 대화의 최신 `AIWACK_Stage34_Local_Offline_Source.zip`(143개 파일)을 직접 검사해 `docs/progress.json`의 완료 1~34, `next_step=35` 및 로드맵 35 `TODO` 확인. 사용자 요청에 반복 기재된 24단계는 이전 보고값이므로 최신 파일의 34단계 완료 상태를 우선함.
- 원본 기획서 `docs/original_project_spec.txt`, 기존 Tkinter·SQLite 코드와 모든 이전 테스트를 보존. GitHub 조회/업로드/커밋/PR/Actions, 외부 서버 및 클라우드 AI API 사용 없음.
- 단계35 범위: **이미 사용자가 작성한 복합 업무 계획**(활성 목표에 연결된 `ready` 계획, 6~30개 단계, 기존 연결 업무 없음)을 **규칙 기반으로 단계별 세부 업무 초안**으로 변환. 원본 단계마다 하나의 미배정 `todo` 업무 제안과 순차 선행 관계 제안, 관리자 확인용 완료 기준 문구 생성.
- **규칙 기반 구조 분할**이지 AI의 새로운 전략 수립, 의미적 업무 분해, 성공 확률 추정, 실제 GGUF 모델 추론이 아니다. 순차 의존성은 가정이며, 실제 순서·담당자·모델·완료 기준은 관리자가 검토해야 한다.

## 구현

- `desktop/task_breakdown.py`: 출처 자격 검사, 계획 내용 SHA-256 지문, 6~30개 단계의 결정적 초안 구성. 원본 문구를 명령으로 실행하지 않음.
- `desktop/storage.py`: 비파괴적인 SQLite `company_task_breakdowns`, `company_task_breakdown_items` 테이블과 관리자 전용 초안 생성/목록/조회/거절/승인 적용 API. 동일 원본 버전 중복 생성 방지, 원본 변경·다른 업무 생성 시 stale 처리, `BEGIN IMMEDIATE`로 동시 승인 직렬화.
- 승인 적용은 **관리자의 명시적 확인 이후에만** `todo` 업무·상태 이력·순차 의존성·의존성 이력을 한 트랜잭션으로 생성. 오류 시 전체 롤백. 생성된 업무는 감사 출처 보호를 위해 삭제 차단(업무 상태·담당자 등 기존 관리 기능은 유지). **AI 모델/외부 프로세스 실행, 자동 업무 완료, 자동 우선순위 설정 없음.**
- 기존 계획 삭제 기능: 미승인 초안은 사용자가 원본 계획을 명시적으로 삭제하면 함께 삭제됨; 적용된 업무가 있으면 기존의 연결 업무 삭제 제한을 유지.
- `desktop/app.py`: 신규 24번째 `복합 업무 세부 계획` Tk 탭. 계획 선택, 초안 생성/미리보기, 관리자 승인 확인 대화상자, 거절, 상태/이력 조회. 기존 23개 탭 순서 유지.
- `desktop/entry.py`: 소스/패키징된 진입점의 `--self-test`에 35단계 데이터 저장·재실행·선행 관계 검사 추가. 실제 Windows EXE를 빌드했다는 의미는 아님.
- `tests/test_task_breakdown.py`, `scripts/stage35_gui_smoke.py` 및 기존 오프라인 GUI 검사 확장. 기존 Stage33 GUI 검사의 탭 개수 고정 조건을 하위 호환적으로 변경.

## 한계와 별도 완성도 지표

- 원본 단계 6개 이상을 1:1로 구조화하며 작업 순서를 일렬로 가정한다. 단계 자체를 의미적으로 더 잘게 쪼개거나 실제 필요 리소스·실행 시간·AI 역량을 평가하지 않는다. 검토용 완료 기준은 템플릿이며 품질 보증이 아니다.
- 업무 초안은 사용자 SQLite에 평문 저장. 원본 계획 삭제 시 미승인 초안도 삭제된다. 기존 데이터베이스는 ZIP에 포함하지 않음.
- Python 소켓 차단 검사는 테스트 프로세스의 소켓 호출을 차단할 뿐 신뢰되지 않은 로컬 모델 실행파일을 OS 수준에서 격리하지 않는다. 이번 단계는 모델 실행 자체가 없다.
- **로드맵 35/100 (35%)**, **실질 제품 완성도 약 12% (주관적 추정)**. 실제 장기 자율 운영·매출·사업 실행·Windows 배포·GGUF 모델 성능은 미검증/미완성. 다음 36단계: 정기 작업 스케줄러.
