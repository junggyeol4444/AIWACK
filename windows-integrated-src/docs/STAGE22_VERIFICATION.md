# 22단계 로컬 기능과 제품 완성도 검증 기록

## 요구 및 구현

- 원본 기획안/100단계에서 22단계는 `회사 목표와 업무 계획 저장`. 이미 11단계에서 운영 목표의 기본 관리 기능을 구현했으므로 이번에는 목표와 연결된 **사람이 작성한 업무 계획**을 영구 저장한다.
- 새 SQLite 테이블 `company_work_plans`(목표 FK, 제목, 설명, 상태, 생성/수정일), `company_work_plan_steps`(계획 FK, 순서, 설명). 단계 23의 독립 실행 작업 또는 자동 명령은 이번 단계에서 만들지 않음.
- 로그인한 관리자만 CRUD, 연결 목표 유효성 확인, 실행 순서 입력 검증 및 원자적 저장. 참조 중인 목표 삭제 방지.
- 기존 `aiwack.sqlite3`를 그대로 쓰는 `CREATE TABLE IF NOT EXISTS` 추가. 기존 계정/직원/목표/조직 관계를 리셋하거나 이전 DB를 삭제하지 않음.
- GUI `업무 계획` 탭: 목표 선택/계획 상태/다중 줄 실행 순서/저장·수정·삭제(확인 필요).

## 별개 지표: 제품 실제 완성도

- 로드맵 진행도는 22/100단계지만 각 작업의 난도와 중요도는 같지 않음.
- 실질적인 자율 운영 회사 기능의 완성도는 정량 검증값이 아니라 **약 8% 내외(대략 5~10%)로 보는 임시 추정**.
- 기초 Tk 데스크톱 앱, 로컬 SQLite, 조직/직원/권한과 모델 호출 인터페이스는 있으나, 검증된 실제 GGUF 추론·자동 업무 엔진·AI 협업·도구 실행·사업/상품/판매/정산·장시간 장애 복구는 미구현/미검증.
- 최종 완성도를 숫자로 객관적으로 증명할 가중치/성능 인수 테스트가 아직 없어 단일 숫자는 참고용.
- 소스 ZIP은 Windows EXE 실행파일이 아니며 실제 Windows PC에서의 EXE 빌드 및 실제 LLM 추론은 확인되지 않았음.
