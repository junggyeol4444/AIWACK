# 사용자 환경/운영 검증 대기
1. Windows 10/11에서 공개 HTTPS 직접 요청 및 사이트별 `robots.txt` 정상/거부 경로 시험.
2. 서비스별 접근·크롤링 조건, 개인정보·저작권 이용 정책을 확인하고 허가된 도메인만 사용.
3. 계정·인증 및 실제 판매 채널 연동은 사용하는 서비스와 실제 권한에 맞춰 별도 통합 개발·실거래 전 검증.
4. GGUF 실제 모델/다중 작업, Windows EXE, T01~T20 인수 조건 및 장시간 무중단 운영 실증.
5. 전체 pytest·Stage63 타이밍 실패 관련 회귀 검증 및 장기 데이터 이관 복구 시험.
6. Firecrawl/Tavily를 직접 활용하려면 도구 계정의 사용량 제한/크레딧 상태 확인(승인 없이 결제하지 않음).
