# 시도 및 시간 제한

- 초기 신규 테스트: 19개 통과, 2개 실패. 기존 HTML 링크 파서가 `.localhost` 주소를 로컬 출처 메타데이터로 거부하기 때문에 신규 테스트의 잘못된 입력이 원인이었음. 제품의 링크 파서 정책을 변경하지 않고 테스트에서 `.local` 도메인을 사용하도록 정정. 이후 신규 테스트 21개 통과.
- 단일 전체 `PYTHONPATH=. python -m pytest -q` 실행은 도구 실행 시간 제한(280초)으로 중단. 로그 마지막은 약 21% 지점. 전체 실패/성공 결론을 내릴 수 없음.
- 전체 `PYTHONPATH=. python -m scripts.verify_offline_runtime` 역시 도구 실행 시간 제한(200초)으로 중단. 표준 출력이 파일에 버퍼링되어 로그가 비어 있음. 일괄 검사 통과라고 보고하지 않음.
- 대체 검증: 연구 영역 329개 통과, 선택한 네트워크 차단 실행 명령 5개 통과. 이것은 전체 회귀 통과와 동일하지 않음.
