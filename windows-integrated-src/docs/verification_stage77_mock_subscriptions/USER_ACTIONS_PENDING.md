# Stage77 사용자 수행 대기 목록

1. Windows 실기기(오프라인) 설치 없는 실행 및 EXE/Tkinter/SQLite 테스트.
2. 실제 구독·취소·환불 운영을 위한 결제 제공자 계정, 웹훅 서명/재시도/멱등성/환불 정책, 계약·세금·개인정보 보호 법무 검토. 명시적 허용 전에는 어떤 API도 연결하지 않음.
3. 실제 고객 신원, 결제 원장, 취소/환불 자격·금액·부분 환불·회계·정산을 독립 검증. 현재 로컬 금액은 Stage72 가정 가격이며 실제 지불 내역이 아님.
4. 실제 GGUF 모델 로드, 전체 프로젝트 회귀, Stage63 병렬 subprocess 시간 임계 문제 분석, 장시간 자율 운영·자원/부하 검증.
5. 관리자가 별도 실행 Tkinter GUI의 실제 사용성 확인 및 기존 전체 앱으로의 통합 승인/요구사항 결정.

**금지 유지:** GitHub 접속 전부, 외부 네트워크/클라우드 AI/API, 승인되지 않은 계정·결제·실제 이메일/게시, 사용자 PC 무단 접근/설치.
