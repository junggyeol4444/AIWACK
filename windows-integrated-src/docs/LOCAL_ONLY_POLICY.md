# 이 대화의 로컬 개발 원칙

- 모든 변경은 이 대화의 로컬 프로젝트 체크포인트 안에서 수행합니다.
- 외부 저장소 전송, GitHub 커밋·PR·병합, GitHub Actions 실행 요청은 하지 않습니다.
- 기존 연결된 GitHub ChatGPT 앱은 사용자의 요청으로 제거했습니다.
- 기존 **원격** GitHub 저장소에 남아 있는 Actions 예약 설정은 이 소스 ZIP의 설정 파일 삭제만으로 중지되지 않습니다. 저장소 운영자는 GitHub 웹 UI의 Actions 화면에서 별도로 예약 워크플로를 끄는 작업이 필요합니다. 이 로컬 ZIP에는 해당 자동화 파일이 없습니다.
- 소스 ZIP과 개발 체크포인트만 현재 대화에서 전달합니다. 예약 시간마다 이 대화가 저절로 코딩을 계속하는 것은 아닙니다.
- 외부 과금 서비스, 계정·결제 및 실거래는 명시적인 승인 없이 사용하지 않습니다.

## 오프라인 검증 기준

- `desktop/entry.py`가 사용자 EXE의 유일한 진입점이며 Tkinter + PC의 SQLite 파일만 실행합니다.
- 구형 `backend/` HTTP 개발 도구는 EXE에 포함되지 않고 EXE에서 실행하지 않습니다.
- `build_windows_exe.bat`는 PyInstaller를 자동 설치하지 않으며 네트워크 호출도 하지 않습니다. 로컬 도구가 준비돼 있어야 빌드할 수 있습니다.
- `python -m scripts.verify_offline_runtime`에서 네트워크 소켓을 차단하고 데스크톱 실행 검사를 합니다.
- 수동 로컬 실행파일 호출 경로는 구현돼 있으나 실제 GGUF 가중치로 추론하는 환경은 아직 검증하지 않았습니다. 완전 로컬 실행을 기본으로 유지하고 클라우드 AI를 기본 또는 필수 구성으로 정하지 않습니다.

## 18단계 모델 연결 정책

- 모델 실행은 네트워크 서버가 아닌 **사용자가 지정한 PC 내부 실행파일의 별도 로컬 프로세스**입니다.
- llama.cpp CLI 또는 llamafile 실행파일과 GGUF 가중치는 사용자 PC에 미리 준비되어야 하며 앱이 다운로드/업데이트/설치하지 않습니다.
- 로컬 모델 연결은 반드시 소유자가 프로필을 등록한 뒤 '선택 모델 추론 시험' 버튼을 직접 눌러야 구동됩니다. 직원 프로필에 모델 자동 연결하거나 자동 업무를 실행하지 않습니다.
- 등록/목록 조회/파일 형식 검사는 프로세스를 실행하지 않습니다. 등록을 지워도 사용자의 GGUF·실행파일은 삭제하지 않습니다.
- 지정한 로컬 프로그램 자체의 네트워크 접속 가능성은 앱이 OS 수준에서 막을 수 없습니다. 신뢰 가능한 엔진 및 방화벽을 사용해야 합니다.
