# AIWACK Stage58 — 이미지·영상·문서 도구 연결 구조 (부분 구현)

기준: Stage57 누적 전체 ZIP 1,119개 파일. 원본 기획안·요구사항 추적표·100단계 로드맵·진행 JSON 확인 후 개발. 사용자 지시대로 54·56·57단계 보류 작업은 재개하지 않음.

## 구현
- `desktop/media_tool_adapters.py`: 내장 이미지 PNG/JPEG, 영상 MP4/WebM, 문서 TXT/MD/PDF/DOCX 7종에 대해 확장자→고정 어댑터→헤더/구조 검사→해시 결과의 로컬 읽기 전용 연결 경계. 외부 실행·동적 플러그인 로딩·인터넷 없음.
- 파일 20MiB 제한, symlink/일반 파일 여부, 크기·mtime·inode 재확인, 내용별 최소 형식 검사. PDF/MP4/WebM/JPEG는 전체 유효성·디코딩 검증이 아닌 **제한된 헤더 검사**. DOCX는 ZIP 중앙 디렉터리·필수 항목만 확인, 압축 해제/문서 실행 없음.
- `desktop/storage.py`: 관리자 권한 검사, 결과 SQLite 추가 전용 기록 및 재로그인 조회.
- `desktop/app.py`: 관리자 로그인 후 전용 탭에서 파일 선택·어댑터 선택·명시적 승인·검사 이력 조회. 취소 시 기록 없음.
- `tests/test_stage58_media_adapters.py` 및 `scripts/stage58_media_adapters_gui_smoke.py`: 파일 형식·거부·SQLite 불변성·로그아웃·실제 Tkinter 취소/승인/이력 테스트.

## 검증과 보류
- 전체 pytest 단일 실행은 시간 제한으로 중단되었으며 성공으로 간주하지 않음.
- 93개 테스트 파일의 중복 없는 24개 그룹 재검증: 한 그룹에서 동시 실행 시간 민감 테스트 1개가 부하 시 임계치 1.5초를 초과(1.78초)하여 **첫 실행 1실패**, 해당 그룹을 단독 재실행하여 43개 통과. 다른 그룹은 전부 통과. 결과는 ZIP의 `docs/verification_stage58_media_adapters/logs/` 참고.
- 신규/56·57단계 관련 pytest 76개 통과. 63개 오프라인 검사 명령(소켓/DNS 차단 + Linux Xvfb Tkinter 포함) 분할 실행 전부 통과. 네트워크 차단은 Python 수준 검사이지 OS 방화벽 증명 아님.
- **58단계 BLOCKED/부분 구현**: 이미지/영상 제작·수정·렌더링, 문서 변환/출력, 실제 코덱/모델/외부 앱 연동은 미구현. 사용자 실기기 Windows/EXE 검증 없음. 다음 **59단계**로 개발 전진. 기존 54·56·57 보류 유지. 완료 개수 54/100개(1~53,55) 그대로.
- 제품 실질 완성도 약 20~25%는 검증된 정량값이 아닌 주관 추정.
