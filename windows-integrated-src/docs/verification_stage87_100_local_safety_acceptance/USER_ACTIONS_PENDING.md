# 사용자 수행 및 별도 시험 대기

1. Windows 10/11 오프라인 실기기에서 Tkinter GUI, 저장/재시작/권한 및 EXE 설치·실행 검증.
2. 승인된 실제 GGUF 모델 파일/실행기 준비 후 GPU·CPU 부하, 모델 출력, 다중 AI 병렬 처리·장시간 안정성 시험.
3. 필요하면 별도 명시적 승인하에 실계정/공식 API/인증/판매채널/결제사 테스트 계정을 안전하게 연동·검증. 현재는 미시도·미검증이며 기술적으로 불가능 판정이 아님.
4. 실제 구독/환불/배송/매출/정산 정책, 법규/세금/개인정보/사업자 등록 및 보안감사.
5. 원본 T01~T20에 따른 실사용 조건 전체 인수 검증; 실제 결제·발송은 모의테스트로 대체 불가.
6. 기존 Stage63 타이밍 테스트 조사, 전체 프로젝트 테스트 및 전체 오프라인 명령 일괄 회귀.
7. 로컬 긴급정지의 실행중인 실제 에이전트/외부 작업 차단 확대 및 사용자 최종 승인.
