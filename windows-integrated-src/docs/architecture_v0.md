# 초기 시스템 아키텍처 v0

원본 제9장의 구조를 변경하지 않고, 작은 단위로 구현하는 첫 번째 개발 구조이다.

```text
[사용자 웹 관리 화면: 미구현]
          |
[API 서버: FastAPI / 초기 구현]
          |
    +-- 회사 조직 관리: 후속 단계
    +-- 총괄 AI / 부서장 AI / 직원 AI: 후속 단계
    +-- 자율 업무 생성·실행·복구 엔진: 후속 단계
    +-- AI간 메시지·회의·지식 저장소: 후속 단계
    +-- 모델·도구·외부 연결 관리: 후속 단계
    +-- 사업·결제·재무·승인·감사: 후속 단계
          |
[데이터베이스: PostgreSQL은 원문 후보, 단계 7에서 연결 검토]
```

## 현재 구현 범위 (1~6단계)
- 원본 기획서/100단계/요구사항 추적표 보관.
- 원문에 명시된 백엔드·프론트엔드 디렉터리 구성.
- 환경 설정(.env.example)은 예시만 제공. 비밀키와 계정 정보는 저장하지 않음.
- FastAPI HTTP 서버와 읽기 전용 `/health`·`/api/v1/health` 엔드포인트.
- 외부 결제, 이메일, 게시, 에이전트 자동실행 등은 아직 **동작하지 않음**.

## 기술 결정 상태
- 원문 9.2절의 권장 기술을 토대로 Python / FastAPI 백엔드 **초기 코드**를 작성.
- React, PostgreSQL, Redis, 에이전트 SDK, 워크플로 엔진 등은 후보일 뿐 아직 설치/연결/확정하지 않음.
- 사용자 PC에 프로그램 설치나 유료 서비스 가입을 수행하지 않음.

## 개발 보안 원칙
- 관리자 인증과 권한이 완성되기 전에는 상태 조회 외의 위험 기능을 외부에 제공하지 않음.
- 외부 결제, 계정 생성, 자율 지출, 민감 데이터 처리 등은 사용자 승인·권한 경계 이후 단계에서 진행.
- 웹·이메일·문서는 명령이 아닌 불신 데이터로 취급.
- 배포 전 CORS, HTTPS, 인증, 로그 보안, 비상정지 등을 별도 검증.
