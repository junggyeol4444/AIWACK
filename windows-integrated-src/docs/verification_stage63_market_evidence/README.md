# 63단계 — 시장 수요 및 경쟁 조사 (오프라인 근거 검토 부분 구현)

원본 기획안 §4.1의 시장 수요·경쟁 상품 조사, 독립적 출처 검증, 정량적 수요·경쟁 분석은 구현하지 않았습니다. 기존 54단계의 **관리자 수동 등록** 로컬 자료를 62단계 사업 후보에 연결하여 주장과 근거의 존재 여부를 기록하는 기능입니다. 외부 인터넷·AI API·GitHub·판매·결제·전송·게시·자동 사업 실행은 수행하지 않습니다.

- `desktop/market_evidence.py`: 수요(`demand`)·경쟁(`competition`) 범주, 지지/반박/맥락 방향, 정확히 일치하는 로컬 원문 발췌(8~240자), 관리자 메모, 출처 원문 SHA-256 대조 및 연결 해시를 SQLite에 기록합니다.
- 로컬 자료 `offline_research_captures`의 출처 URL은 사용자가 입력한 주장입니다. 원문 해시 일치는 **로컬 내용 무결성** 검사일 뿐 출처 진위·실제 시장 수요의 검증이 아닙니다. 복수 발췌를 서로 독립된 출처로 계산하지 않습니다.
- 검토 상태 `unreviewed`/`noted`/`excluded`, 추가 전용 이벤트 및 트리거, 감사 이벤트 SHA-256 확인. 평문 SQLite 파일 자체는 공격자에 대한 불변·암호화 증거 저장소가 아닙니다.
- 관리자 인증/권한을 가진 `LocalStore` 메서드와 Tkinter `시장 수요·경쟁 근거 검토` 탭을 추가했습니다. 관리자 승인 없이는 자료 연결·검토 상태 변경을 수행하지 않습니다.
- 원문 없는 인용·잘못된 ID·중복 연결·비밀정보 형태의 메모·무결성 불일치를 거부합니다. 연결 최대 100개/후보, 검토 이벤트 최대 100개/연결.
- 요약은 로컬 검토 자료의 유무와 방향만 집계하며 `market_demand_verified=False`, `competition_verified=False`, `source_authenticity_verified=False`, `independent_sources_verified=False`를 명시합니다. 경쟁사·수요 통계·시장 규모·가격 데이터는 생성하지 않습니다.

**보류:** 실제 시장/고객/경쟁 데이터 수집 및 출처 인증, 총괄 AI·시장조사부 자동 조사, 객관적 수요·경쟁 검증, Windows 실기기·GGUF 모델 및 장시간 자율 실행. 다음 개발 64단계 ‘사업별 비용·수익 가능성 평가’. 완료 단계 개수는 54/100 유지.
