# 62단계 개발 중 수정 이력

- 첫 신규/61단계 결합 검사에서 신규 테스트 9개 실패: 실행 기록을 생성 후 UPDATE하려 했으나 추가 전용 SQLite 트리거가 정상적으로 차단함. 실행 전 중복과 생성 건수를 계산한 뒤 INSERT 한 번으로 기록하도록 수정.
- 수정 후 실패 1건: 길이 제한을 넘는 결합 가설 설명을 테스트가 성공으로 가정함. 구현은 명시적으로 ValueError로 거부하고 트랜잭션을 되돌리는 동작이었으며, 테스트를 해당 안전 동작 검증으로 수정.
- 최종 신규+61단계 결합 pytest 51개 통과, 신규+구조 검사 26개 통과. 전체 분할 회귀 결과는 logs/regression_groups.json과 개별 로그에 기록.
- 이전 61단계의 병렬 실행 시간 제한 테스트는 61단계에서 실패했던 이력이 있음. 이번 62단계 최종 회귀 결과는 별도 기록하며, 과거 실패를 지우거나 보장된 성능으로 해석하지 않음.
