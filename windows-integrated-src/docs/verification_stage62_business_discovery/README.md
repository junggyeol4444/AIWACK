# 62단계 — 신규 수익 사업 후보 자동 발굴 (부분 구현)

원본 기획안 §4.1의 독립 시장 조사 및 자율 사업 발굴은 구현하지 못했습니다. 로컬 데이터만으로 실제 시장 수요·경쟁·매출을 알 수 없으므로 허위 시장 조사 결과를 생성하지 않습니다.

- `desktop/business_discovery.py`: 관리자가 입력한 대상 고객·문제 가정과 61단계 활성 사업 유형을 결합해 최대 20개 **미검증 가설** 초안을 생성합니다. 동일 유형/대상/문제는 대소문자·공백 정규화 키로 중복을 제외합니다.
- 관리자 수동 검토 상태 `draft`, `shortlisted`, `rejected`; 후보 생성 실행 및 상태 변경의 로컬 SQLite 이력. 감사 이벤트/실행 기록은 SQL 트리거로 UPDATE/DELETE를 거부하며 SHA-256으로 이벤트 데이터 변경을 검사합니다. 데이터베이스 자체는 암호화/변조 방지 저장소가 아닙니다.
- `desktop/storage.py`: 관리자 권한 경계와 트랜잭션. `desktop/app.py`: 후보 생성 확인/취소·목록·검토·이력 조회 Tkinter 화면.
- `tests/test_stage62_business_discovery.py`, `scripts/stage62_business_discovery_gui_smoke.py`: 권한, 입력 검증, 중복 제거, 비활성 유형, 실패 원자성, 기록 위변조, 네트워크 금지, 실제 GUI 검증.

**보류:** 실제 AI 총괄/시장조사부의 자동 사업 탐색, 시장 수요·경쟁·비용 근거 및 독립적인 수익 가능성 분석, Windows 실기기 및 실제 GGUF 검증. 모든 후보는 사용자 입력 가정이며 `source_kind=owner_input_unverified`입니다. 실제 시장 근거·사업성은 검증되지 않았고 판매·배포·결제는 실행하지 않습니다. 다음 개발 63단계 ‘시장 수요 및 경쟁 조사’. 완료 단계 개수 54/100 유지.
