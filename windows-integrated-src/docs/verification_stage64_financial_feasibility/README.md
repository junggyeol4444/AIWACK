# 64단계 — 사업별 비용·수익 가능성 평가 (부분 구현)

원본 기획안 §4.1의 개발/운영 비용 및 예상 매출의 근거·불확실성 평가를 위한 **관리자 입력 가정 기반 산술**만 구현했습니다. 실제 매출·실측 원가·수요 조사·독립 AI 사업 판단을 구현했다고 주장하지 않습니다.

- `desktop/financial_feasibility.py`: 61단계 등록 사업 또는 62단계 후보에 연결되는 오프라인 가정 평가. 단가·월 판매량·단위당 변동비·월 고정비·마케팅비·초기 비용·환불률·결제 수수료·기간을 입력합니다. 부동소수점 없이 정수 원화 및 bp(1bp=0.01%)를 사용합니다.
- 월 가정 매출 = 단가 × 가정 판매량. 월 가정 손익 = 매출 − 환불 추정 − 결제 수수료 추정 − 단위당 변동비 × 판매량 − 고정비 − 마케팅비. 기간 가정 손익 = 월 가정 손익 × 기간 − 초기 비용. **세금, 미지급금, 매출 인식, 재고, 운전자본, 시간가치 등 회계/현금흐름 요소는 미반영**입니다.
- 하향/상향 시나리오는 판매량만 ±25% 조정합니다. 다른 변수가 고정되는 단순 민감도이며 수요 예측이 아닙니다. 손익분기 가정 수량은 기간 전체에 대해 계산하되 월 최대 10억 개까지만 탐색하며, 도달하지 않으면 `None`을 반환합니다. 가정 판매량은 0~100만 개/월, 기간은 1~120개월로 제한합니다.
- 입력·결과·감사 기록 SHA-256 대조, 평가/이벤트 UPDATE·DELETE 차단 트리거, 사용자 인증/관리자 권한, 저장 실패 시 원자적 롤백, 비밀 형태 메모 입력 거부를 구현했습니다. 평문 SQLite의 해시/트리거는 **관리자 또는 OS 권한을 가진 공격자에 대한 변조 방지 증거가 아닙니다.**
- 관리자 전용 Tkinter `비용·수익 가정 평가` 탭은 확인 대화상자, 후보/사업 선택, 가정 입력, 이력·손익분기 가정 결과 조회를 지원합니다. 외부 전송, 결제, 지출, 계정 연결, 자동 사업 승인·실행은 없습니다.

**보류·사용자 확인 필요:** 실제 거래/매출·환불·정산 내역, 원가·수수료·세금 자료, 독립 시장 수요/경쟁 검증, 자율 AI의 수익성 판단, Windows 실기기·실제 GGUF·외부 서비스 검증. 원본 기획안의 실거래 검증 및 자율 판단 완료 조건은 충족하지 못했습니다. 다음 개발 **65단계 ‘총괄 AI의 사업 선택·실행 판단’**. 완료 개수 **54/100 유지**.
