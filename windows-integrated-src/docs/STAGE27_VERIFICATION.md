# 27단계 검증 — 관리자 확인형 로컬 AI 업무 실행기

## 실제 구현 범위

- 기존 26단계 누적 소스 ZIP과 `docs/progress.json`에서 완료 1~26, 다음 27 확인 후 작업.
- 관리자 확인 후 `AI 업무 실행` 탭에서 배정된 AI 직원의 로컬 CLI 실행파일을 **한 번만** 호출해 텍스트 초안을 화면에 표시. 직원 프로필/업무 등록·모델 배정 자체로는 자동 실행하지 않음.
- 실행 시작은 SQLite `BEGIN IMMEDIATE` 트랜잭션으로 `todo` 상태, 선행 업무 완료, 활성 직원·업무 배정·부서/직무 조건·모델 연결·단일 실행 조건을 재검사. 모델 호출 기록과 업무 실행 기록을 동시에 생성하며 `todo → in_progress` 상태 이력 기록.
- 성공 시 `in_progress` 유지(관리자가 직접 검토/완료). 실패·취소·시간 초과는 `blocked`로 변경. 두 감사 기록을 함께 종료하며 DB에 원문 프롬프트/응답/오류 원문은 저장하지 않음.
- 실행 중 다른 업무 실행, 현재 업무 상태/내용 변경, 직원 모델 변경·비활성화·프로필 변경 차단. 업무 실행 이력이 있는 작업은 삭제 거부.
- 프로그램 중단으로 `running` 기록이 남으면 관리자가 실제 모델 프로세스 종료 확인 후 수동 복구할 수 있음. 자동 재시도나 자동 복구 없음.
- 실제 모델 호출은 기존 `desktop/model_runtime.py`의 subprocess `shell=False` 경로만 사용. 도구 실행, 파일 변경, 결제, 외부 서버, GitHub API 호출 기능 없음.
