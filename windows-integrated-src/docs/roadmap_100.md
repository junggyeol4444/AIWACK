신규 등록·보관 상태 변경이 발생하면 다시 승인하도록 승인 토큰도 보강했습니다.
**URL 문자열 일치만 확인**하며 실제 링크의 정상 동작, 웹 출처의 진위, 인용 관계를
인증하지 않습니다. 파일이나 SQLite를 직접 수정하지 않는 사전 검토이지만,
기존 별도 관리자의 명시 승인 시 가져오기는 SQLite에 기록됩니다.
인터넷·DNS·브라우저 접속은 전혀 사용하지 않습니다.
원본 54단계 인터넷 조사 및 자동 자료 수집은 **미완료**, 기존 완료 **53/100**을 유지합니다.
자세한 검증: `docs/verification_stage54_bundle_link_preview/summary.md`.

### 54단계 부분 구현: 오프라인 HTML 자기 출처 표기 사전 검토 (2026-10-14)

- 로컬 HTML의 비활성 `<link rel="canonical">` 및 `<meta property="og:url">` 자기 출처 주장과 관리자가 입력한 URL을 사전 비교 (일치/불일치/형식 오류).
- HTML당 최대 8개 주장 검사 및 최대 4개 예시만 노출, 명시적 관리자 승인 전 경고. 스크립트/외부 URL 실행, DNS 조회, 서버 접속 없음. 기존 승인 토큰은 이미 HTML 원본 바이트를 결속함.
- 자체 표기는 조작될 수 있으므로 출처 검증, 원본 인증, URL 안전성 검사로 간주하지 않음. 원본 54단계 인터넷 자동 조사 완료 조건 유지: **완료 53/100**, **54 진행 중**, 웹 자동 수집 미구현.


### 54단계 부분 구현: 오프라인 HTML base/refresh 이동 지시 사전 경고 (2026-10-14)

- 자료 묶음 등록 전 HTML의 `<base href>`와 `<meta http-equiv="refresh">` 중 URL 이동 지시를 텍스트로 분석. 최대 HTML당 8건 검사, 4건 예시 표시.
- 관리자 입력 URL을 기준으로 동일 출처·다른 출처·형식 오류로 구분하여 사전 검토 상세 화면과 승인 대화상자에서 경고. `base`는 기존 상대 경로 분석기에 적용하지 않음.
- 스크립트·템플릿 등 숨김 영역 무시, `javascript:`/`file:` 및 로컬·비표준 URL의 실행·열람 없이 형식 오류 표시. 단순 시간 재로드는 이동 지시에서 제외.
- 기존 파일 승인 토큰, 중복·출처 버전 비교, SQLite 스키마 및 관리자 명시적 승인 유지. 외부 서버/웹/DNS 브라우저 접근 일절 없음.
- HTML의 이동 지시 표기는 저장 문서의 **자체 주장**일 뿐 출처 안전·진위 증거가 아님. 실시간 인터넷 조사·자동 자료 수집 미구현으로 **54단계 미완료, 53/100단계 완료** 유지.
- 검증 및 제한: `docs/verification_stage54_navigation_directives/summary.md`.

54단계 오프라인 부분 구현 보충 (2026-10-14): 자료 묶음 HTML 등록 전 수동 리소스

경고를 추가했습니다. URL 전문·쿼리는 예시에 저장하지 않고 실제 리소스를 요청하지 않습니다.
