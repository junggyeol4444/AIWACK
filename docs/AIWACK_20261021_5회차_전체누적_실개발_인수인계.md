- 기존 4회차 누적 프로젝트 원본 1047개 파일 모두 보존. 원본 문서 내용은 지우지 않았고 작업용 사본에 이 항목만 추가.

- 기존 `storage.py` LocalStore API 및 `company_office_gui.py` 한글 Tk 버튼에 위 기능 연결. 기존 4회차 GGUF 계획 파싱·승인 무결성·Windows GUI 안전 변경은 보존.
- 통합 검증: 루트 138 PASS; 새 회사 전체 협업 테스트의 문서/고객 기능 4 PASS; 부서 협업 3 PASS, 부서 진행 14 PASS. 장시간 네이티브 전체 일괄 실행은 제한 시간 종료로 최종 PASS 판정하지 않음. 진짜 Windows 실행·EXE 물리 클릭/저장/로그아웃/재로그인·30업무 GGUF 실추론·24h/PG 실서비스 미실행.
