- 공식 문서: https://docs.tosspayments.com/reference (2026-10-26).
- GET /v1/payments/{paymentKey} 단일 읽기 전용 호출. 결제 승인/취소/환불 API POST 호출 코드는 만들지 않음.

- 실키 test_sk/test_gsk/live_sk/live_gsk 계열만 그 조회의 함수 인수로 받고 DB·로그 저장 금지. TLS 검증, 리다이렉트 거부, 외부 URL 입력 불가.
