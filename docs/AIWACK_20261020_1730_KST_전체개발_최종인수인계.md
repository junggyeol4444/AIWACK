- 기존 Windows EXE에서 추가 버튼이 실제 '승인' 버튼을 밀어 실제 클릭 E2E 실패한 경험 있음. 새 버튼은 기존 승인/비상정지/결과 검수 위치 보존. 픽셀 가시성 테스트 반드시 유지.
- 진짜 GGUF 응답 텍스트가 나와도 llama.cpp 프로세스 종료 코드가 0이 아니면 FAIL. 공식 SHA256 고정 CPU 배포본 b11433의 0xC0000374 힙 손상 및 b11748 공식 대체 검사 이력 확인.
- Windows sqlite3.Connection context manager는 자동 close가 아니라 자동 commit/rollback만 수행; TempDirectory 정리 WinError32를 해결하려면 실제 connection.close. Windows 파일/DB 잠금 회귀 유지.
- 자율 직원 모델 실행 정책은 기본 꺼짐·소유자 명시 허용·비상정지/다른 EXE 세션 취소 가능. 상위 기획의 자율회사 목표를 개발하면서도 실제 거래 승인·권한 보호를 우회하지 않는다.
