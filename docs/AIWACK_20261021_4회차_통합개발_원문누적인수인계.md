## 이번 회차 실제 소스 수정 묶음
1. `desktop/company_wide_campaign.py`: 실제 llama.cpp가 입력 프롬프트를 그대로 반환한 경우 그 입력 속의 부서명|제목|지시를 총괄 모델의 **신규 생성 계획이라고 오인하지 않도록** 파싱 경계를 추가했다. `propose()`에서 현재 호출의 프롬프트를 분석기에 넘겨 생성 부분만 사용한다. 실제 모델의 생성된 답변이 없으면 기존 원칙대로 실패하며 가상 지시는 만들지 않는다.
2. 같은 파일 `run_next()`: 30개 태스크 상태값이 전부 `done`이어도 30개 실제 직원-총괄-관리자 승인 증빙에 변조가 있으면 `completed=True`를 돌려주지 않는다. 원본의 불변/승인 검증 절차를 그대로 사용한다.
3. `validation/windows_packaged_real_gguf_queue_e2e.py`: 모델 연결/진단 창 종료 시 전역 `Alt+F4`를 쏘지 않고 정확한 live HWND를 다시 얻어 선택 대화상자에만 Win32 `WM_CLOSE`를 전달한다. 종료 사실까지 확인하며 잘못된/바뀐 핸들이면 실패 처리한다. 이미 완료된 물리 클릭 검증 경로는 줄이지 않았다.
4. 기존 `test_company_wide_campaign.py`에 입력 에코 거부와 30개 완료 상태의 손상 승인 차단 회귀 2개 추가. 새 `test_packaged_gui_modal_safety.py`는 모델 없이 대화상자만 닫는 안전한 대상 지정 보조 검사 2개 (Windows 물리 검증 아님).
