# 매시 30분 GitHub 개발 작업

1. GitHub Actions schedule: 매시 30분 (Asia/Seoul); PC와 별개 실행.
2. 매회 의존성 설치, 기존 pytest, 100단계 진행 상태 확인.
3. 사용자 승인 후 `OPENAI_API_KEY`를 GitHub Actions Secret으로 등록하면 `openai/codex-action@v1`에서 다음 단계 한 개를 개발하고 테스트.
4. 수정 결과는 자동 브랜치와 PR로 제출, main 자동 병합 안 함. 기존 자동화 PR이 열려 있으면 새 작업 중복 생성 안 함.
5. Secret이 없을 때는 AI 코딩 불가: 테스트와 보고만 수행. API 과금 여부를 확인하고 사용자가 설치/연결을 선택할 때까지 기다림.
6. GitHub Actions는 매시 30분 스케줄로 실행 시도하지만 지연·누락 가능; 매시간 60분 작업 보장하지 않음. 공개 저장소에 60일 활동 없으면 스케줄이 비활성화될 수 있음.
7. 사용자 PC 전원 상태 감지는 불가. 금전 결제, 권한 변경, 외부 게시/계정 연결은 승인 없이 실행 금지.
