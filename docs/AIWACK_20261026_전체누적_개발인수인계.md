## 미완료, 미검증
- 29개 역사 소스 누락 원문과 52개 충돌 의미 병합; 전체 15부서·31AI·30업무의 실제 GGUF 장기 자율 협업과 총괄 보고; 상품·서비스 실제 운영 및 권한형 금융 연동의 남은 기능.

- 실제 고객 SMTP/결제/환불/이체/게시/실계정 작업은 이번 회차 실행하지 않음.
- 기존 DB·원본 ZIP·GitHub 기존 소스/로그·모델·브랜치·예약·다른 프로젝트를 삭제하거나 덮어쓰지 않음.

## 최우선 금지 및 다음 순서
- 전체 기능 개발을 먼저 끝낸 후에만 Windows10/11 EXE·실GGUF·T01~T20 전체 통합검증 → 오류 일괄 수정 → 전체 재검증.
- 기존 원본 코드를 처음부터 다시 쓰거나 외부 웹사이트로 전환·임의 모델 변경 금지.
- 외부 실거래/게시/SMTP 발송/환불/이체는 해당 개별 명시 승인 없이 실행 금지.
- 매 실행 실제 원격 main HEAD 재조회, 최신 인수인계·원본 기획·로드맵 읽기, 원본 보존. `expected_sha` 비강제 fast-forward만 사용.
- 동일 채팅방의 맥락을 이어가며 다른 대화로 불필요하게 전환하지 말 것. 특정 채팅방 게시 확약 확인 없으면 보장 주장 금지.
