# AIWACK Windows 데스크톱 배포 사용 안내

이 배포본은 GitHub Windows Server 2022/2025에서 **PyInstaller로 실제 컴파일한 네이티브 `AIWACK.exe`**입니다. Windows 11 개인 PC에서의 직접 검증은 별도입니다. Python, 브라우저, 웹 서버는 필요하지 않습니다.

## 최초 실행
1. ZIP 전체를 원하는 일반 폴더에 압축 해제합니다. `AIWACK.exe`를 더블클릭합니다.
2. 최초 관리자 ID와 12자 이상 비밀번호를 설정하고 로그인합니다. 사용자 비밀번호를 잊으면 복구할 수 없으므로 본인이 안전하게 관리합니다.
3. **AI 회사 운영센터**에서 `15개 부서·31명 구성`을 클릭해 조직 초안을 생성합니다. 실제 AI 실행에는 각 직원마다 모델을 연결해야 합니다.
4. `로컬 AI 모델 연결` 창에서 본인 PC의 `llama-completion.exe`와 GGUF 모델 경로를 설정하고 `실제 모델 1회 호출 테스트` 버튼으로 성공 여부를 직접 확인합니다.
5. 로컬 모델 실행·총괄 AI 지시·직원 업무·결과물 검수는 각각 별개입니다. 결과물을 자동 승인하거나 대외 서비스에 자동 배포하지 않습니다.

## 모델 파일 준비
GGUF 모델과 llama.cpp 실행기는 EXE에 포함하지 않았습니다. 해당 실행기는 **동일 기기의 로컬 파일**로 지정합니다. 인터넷 접속이 가능한 PC에서 배포본의 `Setup_Verified_Local_GGUF.ps1`을 사용자가 직접 실행하면, CI에서 검증된 무료 공개 llama.cpp CPU 릴리스 및 GGUF를 파일 해시 검증 후 내려받습니다. 처음 받는 과정에만 인터넷이 필요합니다. PowerShell 실행은 사용자가 직접 결정해야 하며 자동 실행·보안 우회를 하지 않습니다.

### PowerShell 직접 실행 예시
PowerShell을 열고 압축 해제한 폴더로 이동한 다음:

```powershell
powershell -NoProfile -File .\Setup_Verified_Local_GGUF.ps1
```

실행 후 출력된 `llama-completion.exe`, `.gguf` 경로를 복사하여 GUI에서 모델에 연결합니다. GPU가 아니라 CPU로도 검증된 소형 모델이므로 운영 성능·한국어 문장 품질 보장은 아닙니다. 필요하면 더 적합한 검증된 GGUF를 본인이 연결할 수 있습니다.

## 저장·백업·복구
기본 데이터베이스는 `%LOCALAPPDATA%\AIWACK\aiwack.sqlite3`에 저장됩니다. 프로그램을 닫은 후 DB를 별도 장소에 백업하세요. EXE 삭제로 저장 데이터가 자동 삭제되지는 않습니다. 다른 기기에 이전할 때에는 기존 DB 백업을 보존하고 계정·권한을 확인하세요.

## 현재 기능과 한계
관리자 로그인, 15부서·31직원 프로필, 로컬 GGUF 모델 연결, 실제 모델 호출, 총괄 AI 지시→직원 실행→소유자 보고 수락→산출물 승인→업무 최종 완료, 종료·재실행 보존, 로컬 비상 정지는 Windows Server 2022·2025 **테스트 환경**에서 검증되었습니다.

**31명 각각 호출 성공과 31개 독립 고품질 에이전트의 장기 자율 운영은 다릅니다.** T01~T20 전체 인수, 실제 온라인 판매·고객·결제·정산·매출, Windows 11 개인 PC의 백신/보안/하드웨어 조건과 사용자 실제 업무 품질은 별도로 검증해야 합니다. 영업 성과 및 매출 자료를 생성하거나 이미 발생했다고 표시하지 않습니다.

## 배포 검증
다운로드 출처는 저장소의 `Windows EXE build and real startup check` GitHub Actions 입니다. `AIWACK_Windows_Ready_<OS>.zip` 아티팩트를 내려받고, 포함된 SHA256 파일로 EXE 체크섬을 확인할 수 있습니다. `AIWACK_Integrated_Source_<OS>.zip`에는 검증 시점에 적용한 원본 소스와 운영센터 추가분이 포함되어 있습니다.
